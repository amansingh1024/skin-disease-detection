## 📖 Project Overview

Skin diseases affect millions of people worldwide, and early detection can play an important role in seeking timely medical attention. This project leverages Deep Learning and Computer Vision techniques to classify skin conditions from uploaded images.

Users can upload an image of an affected skin area and receive an AI-generated prediction within seconds.

> ⚠️ This project is intended for educational and research purposes only and should not be considered medical advice.

---

## ⚙️ How It Works

1. Upload a skin image.
2. Image preprocessing is performed.
3. DINOv2 extracts visual features.
4. The fine-tuned classifier predicts the skin disease.
5. Prediction results are displayed through the Streamlit interface.

## ▶️ Installation

### Clone the Repository

```bash
git clone https://github.com/amansingh1024/skin-disease-detection.git

cd skin-disease-detection
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Download Model

Download the trained model from:

https://huggingface.co/amansingh1024/dermavision-ai-model

Place it inside the project directory.

### Run the Application

```bash
streamlit run app.py
```
